## Agent skills

### Issue tracker

Las issues viven en las GitHub Issues del repo, con el CLI `gh`. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Las cinco labels por defecto: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` y `wontfix`. Ver `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `GLOSSARY.md` y `docs/adr/` en la raíz. Ver `docs/agents/domain.md`.

## La prueba en un teléfono

Una prueba por adb, con la demo y un pulso fijo, sigue `docs/agents/prueba-por-adb.md`.
