# Las labels de triage

Las skills hablan de cinco papeles de triage. Esta tabla da la label de GitHub de cada papel.

| Papel en mattpocock/skills | Label en GitHub   | Significado                            |
| -------------------------- | ----------------- | -------------------------------------- |
| `needs-triage`             | `needs-triage`    | El dueño tiene que evaluar la issue    |
| `needs-info`               | `needs-info`      | Espera más información del autor       |
| `ready-for-agent`          | `ready-for-agent` | Especificada, lista para un agente     |
| `ready-for-human`          | `ready-for-human` | Necesita una persona                   |
| `wontfix`                  | `wontfix`         | No se va a hacer                       |
